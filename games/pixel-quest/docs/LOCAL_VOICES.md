# Локальная озвучка Pixel Quest

153 записи текущих реплик Episode 01, AR Инициации и «Побега Нулика» находятся в assets/voices/ru-RU/. Система и персонаж записаны установленным в Windows голосом Microsoft Irina Desktop; у Системы немного медленнее темп. Это один тембр для обеих ролей, не отдельные актёрские голоса. Формат: PCM WAV, mono, 22050 Гц, 16 бит. Размер около 23 МБ.

manifest.json связывает роль и текст с именем WAV. В браузере записи воспроизводятся через Audio с того же сервера после нажатия значка звука. Синтез речи ОС для Pixel Quest не используется; для других игр платформенный UI сохраняет прежний вариант. При отсутствии записи или запрете воспроизведения показывается текст. Музыкальные сигналы по-прежнему генерируются локальным Web Audio.

Собрать и обновить комплект локального сервера:

```powershell
npm.cmd run prepare:local
```

Каталог local-server/public/assets/voices/ru-RU/ содержит готовые записи. Переносите весь обновлённый public/ на сервер. Перезапуск браузера/перезагрузка страницы загружает новую сборку. TLS-ключи и сертификаты держите вне public/.

После изменения реплик или для повторной генерации на Windows с установленным русским голосом:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/generate-local-voices.ps1 -Force
npm.cmd run prepare:local
```

Параметр -Voice задаёт имя установленного Windows SAPI-голоса. При замене голоса используйте -Force. Генерация происходит локально, без сервиса озвучки. Для запуска игры Windows и наличие этого голоса на телефоне не требуются. Имена файлов основаны на роли и нормализованном тексте; при изменении текста появляется новая запись. Старые файлы генератор автоматически не удаляет. Многоточие без слов записывается как пауза 500 мс. Задания task, индикаторы и подписи кнопок, которые раньше не озвучивались, остаются текстовыми.

Проверки:

```powershell
node --test tests/local-voices.test.cjs tests/speech-ui.test.cjs
node tests/local-browser-smoke.cjs --voices
```

Браузерная проверка требует Chrome и предварительно собранный local-server/. Она проверяет реальное начало проигрывания WAV и отсутствие внешних HTTP-запросов. Она не оценивает качество произношения и не заменяет проверку Android/iPhone.

Ограничение: сюжетные таймеры «Побега Нулика» пока не ждут окончания голоса, как и до этой доработки. Следующая реплика может прерывать предыдущую. Синхронизация сюжетных интервалов с длиной WAV и подбор отдельных голосов для персонажей — отдельная работа; текущие тексты и игровые интервалы не изменены.
