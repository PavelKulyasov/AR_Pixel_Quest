# Локальный сервер Pixel Quest

Эта папка после `npm.cmd run prepare:local` копируется в `local-server/` вместе с готовой игрой в `public/`. Переносите на площадку всю папку `local-server/`. Исходники, node_modules и npm на сервере не нужны.

## Быстрый запуск на компьютере

Установите Node.js заранее. Запустите `start-http.cmd` или `node server.cjs` из этой папки. Откройте http://localhost:8080. Сервер слушает все сетевые интерфейсы. PORT меняет порт. HTTP предназначен для проверки на компьютере: камера на телефоне требует доверенного HTTPS.

## HTTPS с готовым сертификатом

Сертификат должен соответствовать имени или IP, по которому телефоны открывают игру. В PowerShell из этой папки:

```powershell
$env:TLS_CERT = 'C:\certs\fullchain.pem'
$env:TLS_KEY = 'C:\certs\privkey.pem'
$env:PORT = '8443'
node server.cjs
```

Откройте https://имя-сервера:8443. Не храните приватный ключ в public/ или в Git. Укажите цепочку сертификатов в TLS_CERT. Продление сертификата организуется отдельно. Проверка игнорированием ошибки сертификата не заменяет доверенный HTTPS.

## HTTPS через Caddy с локальным центром сертификации

Заранее установите Caddy на сервер. Из этой папки запустите `caddy run --config Caddyfile`. Конфигурация использует https://quest.lan, локальный сертификат и раздаёт только public/. Caddy автоматически создаёт локальный центр сертификации; публичный интернет для выпуска такого сертификата не требуется.

Настройте локальный DNS роутера: quest.lan должен разрешаться в постоянный LAN IP сервера на каждом телефоне. Установите корневой сертификат локального центра Caddy на устройства и включите доверие к нему (на iPhone отдельно включается полное доверие). Передавайте только публичный корневой сертификат, не ключи центра. Сам Caddy в комплект не включён. Альтернатива для личных телефонов посетителей — свой домен и заранее выданный публично доверенный сертификат с локальным DNS.

## Сеть и проверка на площадке

Подключите сервер кабелем к роутеру, телефоны — к его Wi-Fi. Разрешите входящий порт сервера в брандмауэре; отключите изоляцию клиентов Wi-Fi, если она мешает доступу к серверу. Сделайте QR-код на выбранный HTTPS-адрес заранее и храните его локально.

Отключите внешний интернет, очистите данные сайта на тестовом телефоне, откройте адрес и пройдите квест, включая загрузку моделей, распознавание маркеров и перезапуск. Повторите на Android и iPhone. Не используйте браузерный режим Offline: он отключает также локальный сервер. Проверьте, что телефон не переключился на мобильный интернет из-за Wi-Fi без доступа в интернет.

Все три пакета 8th Wall 1.0.0 сохранены целиком, включая ресурсы и лицензии. 8frame уже находился в проекте локально. В игровом HTML нет CDN-скриптов. Дополнительные возможности сторонних библиотек (VPS, WebXR input profiles, отдельные декодеры и внешние ссылки помощи) могут обращаться к внешним адресам; их автономность этой сборкой не гарантируется. Проверка запуска в настольном браузере не заменяет физическую проверку AR на телефонах. Синтез речи зависит от установленных в ОС голосов; отсутствие интернета может повлиять на озвучку.

Сервер раздаёт независимые прохождения. Общего мультиплеера, централизованных сохранений и серверной аналитики нет.
